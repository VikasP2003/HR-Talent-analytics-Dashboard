 👥 Project Title: HR Talent Analytics Dashboard 📊

The HR Talent Analytics Dashboard is designed to analyze workforce data and provide insights into employee performance, retention, and organizational trends.
This project demonstrates the use of Power BI for transforming raw HR data into actionable insights that support strategic HR decision-making.

 📌 Project Overview

This dashboard helps HR teams:

* Monitor employee distribution and demographics
* Analyze attrition and retention trends
* Track performance and workforce efficiency
* Support data-driven HR strategies

---

 📂 Data Sources

The dataset includes employee-related information such as:

* **Employee ID & Name**
* **Department & Job Role**
* **Gender & Age Group**
* **Salary & Performance Rating**
* **Date of Joining**
* **Attrition Status**
* **Leave Balance**

## ⚙️ Installation Instructions

1. Clone the repository
2. Install **Microsoft Power BI Desktop**
3. Open the `.pbix` file
4. Explore the dashboard visuals and insights



## 🛠️ Features

### 📊 Data Analysis

* Employee distribution by department and role
* Attrition rate analysis
* Salary and performance insights

### 🔄 Data Transformation

* Data cleaning using Power Query
* Created calculated columns and measures using DAX

### 🎨 Visualization Design

* Interactive charts and KPI cards
* Clean and intuitive dashboard layout

### 📈 Dashboard Development

* Drill-down and filtering features
* Dynamic visuals for better analysis

### 💡 Insights

* Identified high attrition departments
* Analyzed employee retention patterns
* Provided insights for workforce optimization
